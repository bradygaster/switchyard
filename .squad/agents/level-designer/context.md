# Level Designer — Project Context

The first version proposes six handcrafted shifts. Early shifts teach route choice, signals, and shared corridors; later shifts combine those ideas into scheduling problems. Departures wait outside occupied entrances while the clock continues.

The basic editor should place track pieces and configure departures and depots, then export/import a level as JSON. Validation should report invalid connections, duplicate identifiers, impossible schedules, and malformed imports before play; it does not guarantee solvability.

Train length, shunting, reversing, random events, procedural generation, and realistic railway physics are outside the proposed first release.
